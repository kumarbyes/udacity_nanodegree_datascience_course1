# Predict GDP Growth rate using Supervised Machine learning models in sklearn

This datascience project is used to predict the GDP growth rate of a country using random forest regressor from sklearn.

# Table of Contents

## Requirements

-**Python Version**: 3.11.9
-Jupyter notebook was created with this python version. If it works in other versions feel free to use anything.
-Check Requirements.txt file for all the libraries used in the project

# Installations
